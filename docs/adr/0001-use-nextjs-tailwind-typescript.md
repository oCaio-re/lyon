# Adotar Next.js com Tailwind CSS e TypeScript

Para construir a landing page da Lyon Soluções Comerciais, decidimos utilizar Next.js (App Router) com TypeScript e Tailwind CSS em vez de HTML estático puro. Esta escolha oferece tipagem estrita, componentização moderna e prepara a base para futuras expansões (como formulários com Server Actions, integração com APIs de cotação ou área restrita para fornecedores).
